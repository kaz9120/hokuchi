# スライドの言葉

Phase 4 と Phase 7 で開きます。スライドの言葉は、聴衆が一度見て、一度聞いて、意味が取れることを基準にします。10 分の登壇では、聴衆に読み解く時間はありません。本は「体裁のよい美辞麗句を並べても人々の心は掴めません」と書いています (p.279)。

2026-09 Dev's Garden では、言葉への指摘が「ポエムっぽい」「AI っぽすぎて気持ち悪い」「主張が謎」と繰り返されました。ここに書くことの多くは、その指摘から来ています。

## 1. 平叙文で書く

主語と述語がそろった、一度で意味が取れる文にします。書いたら 1 枚ずつ「これを声に出して聞いた人が、一度で意味を取れるか」を確かめてください。取れないなら、主語と目的語を補った平叙文に書き直します。

Claude が書くと出やすい癖は次の 4 つです。

- 抽象名詞で締める。「残ったのは、人と人のあいだでした」
- 対句にする。「AI が速くするのは手段の実行／目的の共有は速くならない」
- 「〜のほう」「〜だけ」で余韻を作る
- 狙った言い回しを選ぶ。「あとで高くつく」より「リスクが高い」のように、そのままの言葉を選びます

## 2. 造語と比喩を、定義なしに出さない

- 会話の中で話者が使った比喩 (「根っこ」「三行目」) を、そのままスライドに載せないでください。一般の言葉に置き換えます
- 新しい概念の名前 (「増幅器」など) を出すときは、初出の前か同じスライドで、何を指すかを説明します。説明できないなら、名前を使わずに中身を書きます
- 「〇〇の話」「三つの攻め方」のように、中身を言わない見出しは書きません。見出しには、そのページで言うことを書きます

本は比喩そのものを禁じてはいません。具体物で抽象概念を運ぶ視覚的な比喩 (レゴ、ダイヤル錠) を称賛しています (p.182-183)。退けているのは、現実とつながらない安っぽい比喩です (p.47, p.180)。

## 3. 用語と固有名

- 社内の用語は、社内の一次資料にある正式名称と定義をそのまま使います。言い換えないでください
- 初出は正式名称で書き、省略形は 2 回目から使います
- 名前が聴衆の理解に効かない固有名 (社内の会議名・施策名・チャンネル名) は、画面に出しません。中身で説明します
- イベントのテーマや募集文にある言葉は、なるべくそのまま使います。聴衆はその言葉を持って会場に来ています

## 4. デッキ全体の表記の約束

Phase 4 の最初に次の 3 つを決め、デッキ全体で揃えます。本は、句読点や見出しの書式を全スライドで一貫させるよう求めています (p.171)。

- statement と headline の文末。体言止めにするか、文にするか
- 句点を付けるか。付けるなら全部に付け、付けないなら全部外します
- 読点の扱い。短い statement と箇条書きには読点を打ちません。読点が要る長さなら、改行するか文を分けます

改行は `\n` で、意味の切れ目か句点の位置に入れます。

```
AIを入れたら
チームは強くなるのか
```

1 行目の末尾に読点を置きません。改行が区切りの役を担うためです。

## 5. 事実と引用

- 推測を事実として書かないでください。会議で出た仮説や、話者がそう感じているだけのことは、その旨を書くか、画面から外します
- 引用は原文を開いて確かめ、原文どおりに写します。引用箇所 (資料名・ページ・年) を添えます
- 公開してよい情報かは、話者に確かめます。社外に出していない数字や事業の状況は、話者の許可なく載せません

## 6. 数字と細部

- 主張を際立たせない細部 (日付、所要時間、人数、担当の会議名) は画面に出しません (p.42)。話す必要があれば notes に書きます
- 見出しに数字だけを入れません。「43倍」より「デプロイ数の推移」のように、何の数字かを書きます。変化を見せたいなら、期間も添えます

## 7. 口語の度合い

画面の言葉は、話し言葉より少し硬い書き言葉にします。「外に出しています」のような砕けた表現は避けます。notes は話者が話す言葉なので、話者の口調で書いてかまいません。

## 8. 仕上げに Gemini を通す

Phase 7 で、画面の文字を proofreading-ja-with-gemini スキルで Gemini に添削させます。Gemini は文脈を持たないので、修正案は 1 件ずつ採否を判断します。

- 採るのは、表記と語法の直し (不自然な語順、硬すぎる・砕けすぎる表現、読点) です
- 主張・事実・用語 (社内の正式名称) を変える案は採りません
- Gemini に全体を書き直させると、ポエムが別のポエムに置き換わるだけのことがあります。直った箇所だけを採ります
