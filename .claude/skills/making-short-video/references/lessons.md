# 使い込んで分かったこと

作るたびに足します。ドキュメントを読めば分かることではなく、試して初めて分かったことだけを書きます。日付と CLI の版を添えてください。挙動は版で変わります。

## 1. プレビューの静止画と、書き出した MP4 が違うことがある（2026-11-10、v0.9.26）

シェーダー切り替えの起点のシーンに、Claude Design 向けガイドの雛形どおり `style="opacity:0"` を付けた。`snapshot` では見えたのに、MP4 では 5.0〜7.15 秒が真っ黒だった。`opacity:0` を外すと直った。2 つ目のシーン（切り替えの行き先）には付けたままで問題なかった。

確認は必ず MP4 から切り出したコマで行う。

## 2. Claude Design 向けガイドの雛形は、スキルの検査に通らない（2026-11-10、v0.9.26）

`docs/guides/claude-design-hyperframes.md` の Skeleton A は、シーンの表示を `tl.set("#s1", { autoAlpha: 0 })` で切り替える。スキルの `check` はこれを `gsap_animates_clip_element` のエラーにする。シーンに `class="clip"` と `data-start` / `data-duration` を付ければ表示は自動で切り替わるので、`autoAlpha` の行を消す。

ガイドの考え方（6 シーン、登場後も何かが動く、シェーダーは山場だけ）は使える。書き方はスキルに合わせる。

## 3. 文字を書き換えるコールバックが、書き出しで効かなかった（2026-11-10、v0.9.26）

タイマーの数字を `onUpdate` で `textContent` に書き込んだら、+0:52 のまま止まった。数字を縦に並べた帯を `y` で動かす方法も、理由は分からないまま動かなかった。

効いたのは、9 つの数字を同じ位置に重ね、`tl.set(el, { opacity: 1 }, 時刻)` で 1 つずつ見せる方法。数字や文字が変わる表現は、この形にする。

## 4. 音の素材には CC BY が混ざる（2026-11-10）

`media-use resolve --type sfx` は Openverse から取ってくることがあり、CC0 と CC BY が混ざる。`.media/manifest.jsonl` の `provenance.license` と `credit` に記録が残る。CC BY は投稿のどこかにクレジットが要る。

## 5. 用意できる効果音の質（2026-11-10）

- 衝撃音とタイマーの秒針は、狙いどおりの音が取れた
- 「ペンで線を引く音」は見つからず、同梱の短いスウッシュで代わりにした
- クリック音は小さく、`data-volume` を上限近く（3.9）まで上げた。`data-media-start` で鳴り始めに合わせないと、無音の区間を鳴らしてしまう（`check` が `audio_clip_silent` で教えてくれる）
