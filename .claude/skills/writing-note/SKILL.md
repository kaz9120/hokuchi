# note を研ぎ澄まして書く

このスキルは、題材から公開までを一本で通します。完成の姿は 2 つです。`~/Hobby/hokuchi-private/notes/<slug>/index.md` (公開リポジトリの外) に置いた原稿と、そこから note に貼って公開した記事です。

決めるのは話者で、Claude は話者の言葉を記事に組み立てます。

## 段ごとに、その段のファイルだけを開く

手順は段ごとのファイルに分けてあります。いまの段のファイルだけを開き、ほかの段のファイルは開きません。1 つの段で読む規則を少なくするほど、出てくるものの質が上がります。とくに書く段は、規則を読んでから書くと、正確でも誰も最後まで読まない記事になります (2026-11 に同じ材料から書かせて伏せて比べたところ、短い頼みだけの版が、規則を全部読んだ版より上でした。先に骨組みを決めて渡した版よりも上だったので、書く前の構成の段は外しました)。

| 段 | Phase | ファイル | studio のステップ | 関門 |
|---|---|---|---|---|
| 伝えたいこと | 0〜2 話者の言葉・読者・芯 | `steps/core.md` | 伝えたいこと | 承認 |
| 書く | 4 | `steps/draft.md` | 原稿 | |
| 確かめて直す | 5〜6 lint・素材照合・読者役 | `steps/check.md` | 原稿 | `<!-- 聞く -->` が残っていない |
| 出す | 7 タイトル・タグ・見出し画像 | `steps/publish.md` | 公開 | |
| 振り返り | | `steps/retro.md` | 出した後 | |

原稿を持ち込まれたとき (「見てほしい」「レビューして」) は、確かめて直す段から入ります。

studio の中では、studio が段とファイルを渡します。渡された段のファイルに従います。候補は会話の文に埋めず `proposals.yaml` に書き、確定した値 (`work.yaml`) は書けません。`hokuchi-note` が見つからないときは、リポジトリのルートから `node tools/notes/cli.mjs <サブコマンド>` で同じように動きます。

## この 4 つを外さない

1. 話者の言葉が原料です。Claude は作文しません。記事の文はどれも、元になった素材 (話者の言葉・画像・ログ・ページ・公開されている事実) の箇所を指せます。複数の箇所を 1 文に畳んでもかまいません。判定の基準は、話者がその文を読んで「そう考えている」と言えるかです。足りなければ話者に聞きます。話者の下書きへの指摘 (「AI っぽい」「ポエム感」「主張が謎」) の大半は、Claude が素材の外から足した文に向いていました。そのまま公開された版は、どれも話者の言葉を書き言葉に直したものです
2. 中身は話者から、組み立ては大胆に。Claude が作らないのは中身 (描写・数字・気持ち・教訓) で、組み立ては Claude の仕事です。いちばん強い数字や場面を冒頭に置く、見出しに読者が先を読みたくなる主張を立てる、話者が答えにたどり着いた瞬間 (計算して数字が出た、比べて違いが見えた) を場面として見せる。ここを控えると、正確でも誰も最後まで読まない記事になります。面白さは、話者しか持っていない細部と、その見せ方から来ます (`references/interest.md`)
Claude が作らないもの・Claude がすること・話者に聞くことの境界は次のとおりです。

| 区分 | 中身 |
|---|---|
| 作らない | 様子の描写、数字、気持ちの推測、教訓、因果 (話者が言っていない「だから」「そのせいで」) |
| Claude がする | 複数の発言を 1 文に畳む、順序を入れ替える、節の主張を話者の語で 1 文にする、冒頭と見出しを立てる、前提・場面・話の向きを示す言葉を足す、話者が言った問い・理由・決めたことを、考えた順の 1 本の線につなぐ (つなぎ目のどちらの端も素材にある) |
| 聞く | 理由と因果が素材に無いとき、芯の中の抽象語の中身が無いとき、山場の場面の細部が無いとき |

3. 読者の目が滑らない記事にします。AI が書く文章は、どの段落にも同じだけ手をかけ、要約と言い換えが続くので、読んでいて頭に入らず目が滑ります。厚く書く所と短く通る所を作る「密と粗」(`references/somitsu.md`) は、それを防ぐ手段の 1 つです。書く前に割り振る枠ではありません。書いた後に、読者役が読み飛ばした段落を見つけて直します (`steps/check.md`)
4. 話者の声で書きます。です・ます でつなぎ、接続語を残し、読点を減らします。Claude からは常体を足さず、短文の連打で「リズム」を作りません (`references/voice.md`)。文章は一方向的なものとして書き、「私はこう思う」「私はこうした」を書きます。共感は求めません
