# AI っぽさの型

Phase 4 で書き終えたら、このファイルで原稿を点検します。Phase 6 では文脈を持たないサブエージェントにも同じ点検をさせます。

発表の絵コンテにも当てます。1 の層と 2 の層は、画面の言葉と「話すこと」の両方に当てます。ただし 2 の層の「見出しの言い換えから入る」と「結びを抱負や教訓にする」は記事の規則なので、発表には当てません (発表の締めは `crafting-presentation/SKILL.md` の Phase 6 条件 3 のとおり中核メッセージで閉じ、画面の見出しと話すことは同じことを言ってかまいません)。3 の層のうち、「話し言葉をそのまま写す」「話者の言い直しを全部拾う」「話している場を、記事に持ち込む」「指示語の受け先がない」「感情の語に中身がない」は「話すこと」にも当てます。`voice.md` の「使わない言葉」も当てます。口癖の程度の語は、話すことでは 1 シーンに 1 つまで残してかまいません。素材照合の検査は、これらを「落ちた温度のある言葉」として書き戻しません。受けと留保の数は `crafting-presentation/references/language.md` の 7 に従います。です・ます の割合と読点の規則は記事の規範なので、「話すこと」には当てません。「話すこと」の基準は `crafting-presentation/references/language.md` の 7 にあります。

話者は Claude の下書きを読んで、「びっくりするくらい AI っぽい」「ポエム感」「読点が多すぎる」「主張が謎」と何度も返しています。下の型は、その指摘と、話者が公開前に直した箇所から集めたものです。1 つずつは小さくても、3 つ重なると読み手は「AI が書いた」と気づき、そこで読むのをやめます。

型は 3 つの層に分かれます。上の層ほど重く、下の層の直しでは取り返せません。

## 1. 中身の層 — 素材に無いことを書いている

いちばん重い型です。文がどれだけ自然でも、話者の体験でない文は、話者が読めばすぐ分かります。

| 型 | 例 (Claude の下書き) | 直し方 |
|---|---|---|
| 素材に無い描写を足す | 「会場を沸かせていました」 | 話者が言っていない様子は書きません。話者の言葉が「力強さを感じた」までなら、そこで止めます |
| 素材に無い数字や読み替え | 画像の「1日6時間」を「30時間」と読み替える | 数字は、素材や画像に写っている表記のまま書きます |
| 画像から話者の言葉を作る | 話者が何も話していない利用記録の画像から「また毎日喋って入力している」と書く | 画像は、話者がそれについて話した中身を見せる道具です。話者が触れていない画像は、何を言いたいかを聞くか、使いません |
| 話者の留保や撤回を取り違える | 話者が理由の 1 つだけを打ち消したのを、ほかの理由まで打ち消したことにする | 撤回や留保が何に掛かっているかを、素材の前後で確かめます。決めきれなければ話者に聞きます |
| 聞き手の案を、話者の考えとして書く | 会話の相手 (Claude など) が出した案に話者が「それは良さそう」と答えたのを、「最初に浮かんだのは〜でした」と書く | 誰が出した案かを素材で確かめます。話者が評価しただけの案は、「相手から〜という案が出て、それで数えることにしました」と、出どころと決めたことを書きます |
| 他人の好意を事実として書く | 「違和感なく最後まで聞ける発表だった」 | 「〜と言ってもらえました。お世辞もあるだろうと思います」と、受け取った側の言葉で書きます |
| 体感を言い切る | 「引っかかることが、ほとんどありません」 | 数字で示せない体感は「減ったと感じています」と受けます |
| 留保を重ねる | 「〜かもしれません」「〜なのかもしれません」が同じ段落や同じ状態に 2 回以上並ぶ。「〜という気持ちでいます」のような言い換えで受けの数を避ける | 1 つの主張の留保は 1 回にまとめます。言い換えで避けず、断定か 1 回の受けにします。記事の回数の目安は `voice.md`、発表の「話すこと」の目安は `crafting-presentation/references/language.md` の 7 にあります |
| 理由を飛ばして出来事を並べる | 「作る側に移った。改善をやめた。再開した」 | 出来事の間の「なぜ」は、素材に無ければ書く前に話者に聞きます。推測で埋めません |
| 記事の役に合わない材料を持ち込む | 感謝の記事に、他社の制度終了の事例を足す | 材料の中で熱のある言葉でも、記事の役に合わなければ使いません |

書いた文のそれぞれについて、元になった素材の箇所を指せるかを確かめます (複数の箇所を畳んだ文でもかまいません)。判定の基準は、話者がその文を読んで「そう考えている」と言えるかです。Claude がしてよい編集と、作ってはいけない中身の境界は、SKILL.md の「この 4 つを外さない」の表にあります。指せない文は消すか、話者に聞く問いに変えます。

## 2. 組み立ての層 — 型で畳んでいる

| 型 | 例 | 直し方 |
|---|---|---|
| 抽象的な対句で締める | 「実装は渡しても取り返せる。判断は、渡した回数だけ自分の中から消えていく」 | その場では良く見えても、後で「意味不明」と言われます。何が起きたかの事実に落とします |
| 抽象名詞や「〜のほう」で余韻を作る | 「残ったのは、人と人のあいだでした」「変わったのは私のほうだった」 | 余韻を作るための文は消します。言いたいことがあるなら、平叙文でそのまま書きます |
| どの段落も同じ型で畳む | 段落の最後の 1 文が、毎回その段落の要約や教訓になっている | 段落の最後に要約を置きません。次の段落が始まれば、読み手は前の段落を理解しています |
| 話した順に並べる | 見出しの順が、素材で話者が話した順と同じ。タイトルの数字が最後の節まで出てこない | 結論か、いちばん強い数字・場面を先に置き、読者の問いの順に並べ替えます |
| 見出しの言い換えから入る | 見出し「緊張した」の直後に「当日は緊張しました」 | 見出しの下は、見出しの中身を支える事実から始めます |
| タイトルのフックを冒頭で繰り返す | タイトル「やめた理由が、もう思い出せない」の冒頭に「その理由が、いまはもう思い出せません」 | タイトルが言っていることは、冒頭では事実から入り直します |
| 同じ言い回しを節をまたいで使う | 「寝ている間に」が 3 回出る | 2 回目からは別の事実で書くか、消します |
| 結びを抱負や教訓にする | 「活動ログをとることに、もっと命をかけていきたい」 | 次のアクションで終えます (「次は、活動ログをとる仕組みの整備をがんばります」) |
| 見出しを比喩にする | 「懇親会の話は手からこぼれ落ちる」 | 見出しは、その節の主張そのものにします (「損失なく記録するのは難しい」) |

## 3. 文の層 — 読点と文末

| 型 | 例 | 直し方 |
|---|---|---|
| 短い句のあとに読点を打つ | 「6月末に、音声入力をやめました」「評判も、背中を押しました」 | 主語や時の短い句のあとには打ちません。読点は、打たないと読み違える所にだけ打ちます |
| 短文を同じ調子で並べる | 「選べる幅は広がった。でも面倒になった。だから減らした。」が段落ごとに続く | 短文の連打は、山場の 1 か所だけにします。ほかは「〜のですが」「〜ので」でつないだ、普通の長さの文にします |
| 体言止めを連打する | 「〜を売ること。〜を支援すること。」が続く | 体言止めは、話の向きが変わる所に 1 回だけ使います。並べるなら、文でつなぎます |
| 常体を差し込む | 「9月15日で止まった。」 | 基調は です・ます です。Claude からは常体を足しません。常体は、話者が自分で選んだ一文だけです |
| 接続語を落とす | 「6月になると、開発のやり方が変わっていました」 | 話の向きが変わる所には「ところが」「それでも」を残します。話者は 4 回続けて、消された接続語を戻しています |
| 話し言葉をそのまま写す | 「足したり引いたり」が何度も出て、いつ何をしたのか分からない | 曖昧な動作の言い方は、伝えたい中身 (「何を話すかの取捨選択に時間をかけた」) に置き換えます。対象への評価・比喩・素の反応は、話者の語のまま残します (`voice.md` の「話し言葉を、中身で書き直す」) |
| 話している場を、記事に持ち込む | 録音中に名前を度忘れしたことを、旅の出来事として書く。資料を読みながらの相づちを順に書く。話した時点の「〜したいと考えています」「この会話のあと」が、「〜を削除しました」と同じ記事に混ざる | 素材は、話者がその場で話したものです。言いよどみ・相づち・その場の時点は、記事の中の出来事ではありません。記事に書くのは、決めたこと・気づいたこと・その理由・見たもので、時点は書いた日から振り返った形 (すでにしたことは過去形) に揃えます |
| 考えたことを「〜と思いました」で並べる | 「〜と思いました。〜と感じました。〜と思ったのです。」が段落ごとに続く | 考えた中身を、そのまま主張として書きます。受け (「〜と思います」) は芯と体感の所に置けば足ります (`voice.md`) |
| 自分の発言を引用する | 「そのとき Claude Code にはこう話しています。『〜』」 | 書き手は自分なので、自分の言葉は地の文で書きます。引用にすると他人事に聞こえます |
| 話者の言い直しを全部拾う | 「数字では示せない」「具体を挙げろと言われると厳しい」「体感です」が同じ節に並ぶ | 同じ中身は、いちばん具体的な 1 回だけにします |
| 前置きの句が長い | 「正直に書くと、」 | 「正直、」に縮めます |
| 指示語の受け先がない | 「その後のアップデート」 | 期間や対象を具体的に書きます (「前回の記事から今日までの 2 か月」) |
| 感情の語に中身がない | 「勝てなくても割に楽しくて」 | 何が楽しかったかを添えます (「勝てなくても強い人と将棋できるのが割に楽しくて」) |
| 比較の基準が書き手の頭の中にある | 「会議室らしい部屋かと思った」 | 想像の側も具体に書きます (「狭いビルの一室」) |

lint は、このうち数えられるもの (読点の多さ、常体の混ざり、段落の中の留保、「〜と思いました」の連続、短文の連打、型どおりの言い回し) だけを見ます。1 と 2 の層は、lint では見えません。

## 点検のしかた

1. 1 の層から見ます。素材と原稿を並べ、出どころの言えない文に印を付けます
2. 2 の層を見ます。各段落の最後の文と、各見出しの直後の文を抜き出して並べます。同じ型が 3 つ以上並んでいたら、型で畳んでいます
3. 3 の層を見ます。声に出して読み、息継ぎの位置と読点の位置がずれている所を直します

直すときは、型を別の型に置き換えないでください。対句を消して別の対句を書くと、AI っぽさはそのまま残ります。迷ったら、話者の言葉に戻ります。
