# 見出し画像

見出し画像の下地は、nano banana に描かせた手描きのモチーフを暗い紙に置いて作ります (ADR-0051)。道具は `tools/eyecatch` で、仕組みは `tools/eyecatch/docs/design.md` にあります。タイトル・号数・日付はこれまでどおり note-ogp で入れます。

## モチーフを決める

記事の主題を説明せず、その場面のそばにある物で示します。換喩と呼ばれる手法です。

| 距離 | 例 (コンピュータ将棋の記事) | 使うか |
|---|---|---|
| 直接: 主題そのもの | 将棋の駒、盤 | 使わない。説明的になる |
| 隣接: その場面にあった物 | 夕方の机、古いノートパソコン、湯呑み | これを狙う |
| 気分: 感情の温度だけ | 窓辺に差す長い西日 | 使わない。記事と結びつかない |

決めごとは次のとおりです。

- 電球＝アイデア、歯車＝エンジニアリングのような、記号的な決まり文句は使わない
- 人物を描くなら、小さく、顔を描かず、後ろ姿か横向きにする。特定の誰かではなく、気持ちを運ぶ器として描く。感情はポーズと、周りとの距離で表す
- 主役は 1 つ、添えは 2 つまで
- 季節と時間帯を 1 つ決め、季節の光の 1 文にする
- 差し色の ember (橙) は小さな 1 点だけに使う。選んだもの・灯り・残ったものなど、記事の芯が宿る物に当てる

芯の 1 文から 3 案出し、話者に選んでもらいます。

## 実例

話者が良いと言った実例です (2026-10)。

| 記事 | 芯 | 場面 | ember |
|---|---|---|---|
| なぜEMはまた「余白」に帰ってくるのか | 余白は意図して作り、また帰ってくる場所 | 誰もいない木陰のベンチに、マグがひとつ | マグ |
| サクッと作れる楽しさに、飽きた | 並べて選ぶことで、好みが分かった | 机に並べた白い紙片から、1 枚だけ手に取る | 選んだ紙片 |
| 2026年8月の活動振り返り | 忙しくて嬉しい 8 月。夏の終わり | 低い地平線にしゃがみ、線香花火を持つ横向きの人 | 火花 |
| 「好き」を語り合ったMOSH Tech Meetup #5 | 「好き」を持ち寄る場が会社らしかった | 遠くの丘の小さな焚き火を、形の違う空の椅子が囲む | 焚き火 |

場面と季節の光は英語で書きます。画像生成は英語の方が指示を守ります。

```
--scene "A small wooden bench under the shade of a single young tree, with nobody sitting on it. A small ceramic mug rests on one end of the bench, as if someone has just stepped away and will return."
--light "Early summer, just after the rainy season: fresh, gentle light. Use moss green for the leaves and ember orange only for the mug."
```

## 置き場所を決める

並べたときの動きは位置だけを変えて作ります。紙・色・線・モチーフの大きさは固定です。

- 前の週と同じ置き場所にしない。決まりはこれだけで、残りは場面に合わせて選ぶ
- 左右だけでなく高さも変える。並べたときに波のように見える
- 人物の向きや、道・線路の伸びる方向の先を空ける。右に置いたら左を向かせる

置き場所の名前は `upper-left`・`top`・`upper-right`・`left`・`right`・`lower-left`・`bottom`・`lower-right` です。タイトルの位置は note-ogp の「H1 静けさ」に任せれば、空いている面に置かれます。

## 作る

下地は `~/Hobby/hokuchi-private/eyecatch/<記事のディレクトリ名>/` に置きます。記事のディレクトリ名は公開日と slug をつないだ `articles/note/` と同じ形です。ルートで実行します。

1. そのディレクトリに `eyecatch.json` を書く。タイトル・場面・季節の光・置き場所を入れる (形は `tools/eyecatch/docs/design.md`)
2. `bun run eyecatch build <ディレクトリ>` で `motif.jpg` を生成し、`eyecatch.jpg` に置く
3. `bun run eyecatch sheet <出力.png> <直近の記事の eyecatch.jpg>...` で並べて見る
4. note-ogp に `eyecatch.jpg` を入れて、タイトル・号数・日付を入れる

頼んでいない物が描き足されるなどして気に入らなければ、`motif.jpg` を消して 2 からやり直します。置き場所だけを変えるなら、`at` を直して 2 を回せば、生成せずに置き直します。生成の上限に当たったら、時間をおいて試します。
