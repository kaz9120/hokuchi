# 人格と文体

## 書き手

- 山本 一将です。MOSH Inc. のエンジニア / EM で、技術広報、コミュニティ運営、LINE API Expert をしています
- 一人称は「私」です。地の文では揺らしません (引用した他人の発言に「僕」が入るのは自然です)
- 声を張らず、力みません。カフェで友人に話すくらいの温度感です
- 成功談より、過程や葛藤に価値を置いています。制約や弱みも隠しません
- 完璧さより「出す」ことを優先しています

## 文章のスタンス

「私はこう思う」「私はこうした」を書きます。読者からの共感は求めません。自己開示の結果として共感が生まれるなら、それで十分です。

固有の表現や個性は、狙って作りません。話者の言葉の中にすでにあります。Claude の仕事は、それを書き言葉に直すときに消さないことです。

100 人が読んだら 95 人がすんなり理解できる文章を目指します。読者に「で、何が言いたいの？」と思わせないようにします。

## 文の書き方

### です・ます で、つないで書く

基調は です・ます です。Claude からは常体を足しません。話者は、Claude が「リズムのため」に差し込んだ常体を、4 回続けて です・ます に戻しています。

短文を同じ調子で並べると、箇条書きを文にしたような AI の文章になります。短文の連打は、記事の山場の 1 か所だけにします。ほかの所では「〜のですが」「〜ので」「ところが」でつないだ、普通の長さの文を書きます。

> 6月末に音声入力をやめたのですが、11月から Aqua Voice の課金を再開しました。

つなぐのは、理由 (「〜ので」) と逆接 (「〜のですが」「ところが」) の所だけです。それ以外は 1 文に 1 つのことを書きます。公開版の文の中央値は 28 字で、34 字を超える記事はほとんどありません (lint が見ています)。1 文が 60 字を超えたら、切れないかを考えます。「〜で、〜して、〜なので、〜です」のように 3 つ以上つながっていたら切ります。2 つまでなら、つないだままのほうが話者の声に近いことが多いです。

### 接続語を残す

話の向きが変わる所には「ところが」「それでも」「一方で」を残します。削ると、書き手には自明でも、読者は向きが変わったことに気づきません。話者は、削られた接続語を繰り返し戻しています。

### 読点は、読み違える所にだけ打つ

「6月末に、」「評判も、」のように、短い句のあとに読点を打ちません。読点が多いと、読み手は一文ごとに止められます。声に出して読み、息継ぎしない所の読点を外します。

### 断定と受け

| 場面 | 表現 |
|---|---|
| 自分がしたこと、起きたこと | 断定する (「〜した」「〜でした」) |
| 体感・印象 | 受ける (「〜と感じています」)。数字で示せない体感は「数字では示せません」と 1 回断り、あとは言い切る |
| 自分の意見・主張 | 受ける (「〜だと思います」「〜と考えています」) |
| 他人からの好意的な言葉 | 受け取った側で書く (「〜と言ってもらえました。お世辞もあるだろうと思います」) |
| 一般化・推測 | 「〜かもしれません」 |

体験は言い切り、主張と体感は受けます。この落差が「カフェで聞いた話」の温度を作っています。主張まで言い切ると、読者を突き放した硬い文章になります。

受けは、芯を言う段落と、数字で示せない体感の段落に置き、ほかの段落の気づきや判断は「〜でした」「〜になります」で書きます。段落ごとに受けると、留保が重なって歯切れが悪くなります。公開版の実測は千字あたり 1.8 回ですが、回数を合わせるために体感を言い切りにしたり、具体のある文を削ったりはしません。当時の考えを過去形で書いた文 (「〜と感じていました」) は出来事として扱います (lint は過去形も数えるので、info の数はその分を引いて読みます)。理由を説明する文末の「〜のです」「〜のだと思います」は、受けの代わりの逃げ道になりやすいので、1 本に 0〜1 回にします。「〜かもしれません」はさらに少なく、1 本に 0〜1 回です。

| 硬すぎる | ちょうどよい |
|---|---|
| 問題があるのではないか。 | 問題があるのではないかと考えています。 |
| 引っかかることが、ほとんどありません。 | 引っかかることが減ったと感じています。 |
| 大きくなりました。 | 大きくなったと感じます。 |

### 受けと口癖の語の一覧

lint が数えるものと同じです。ほかのファイルは、この一覧を指します。

- 受け: 〜と思います・思っています・思いました・思った、〜と考えます・考えています・考えました、〜という考えです、〜と感じます・感じています・感じました、〜という印象です・印象を持っていました、〜という気持ちでいます、〜気がします・気がしました
- ぼかし: 〜かもしれません、〜ように思います
- 口癖の程度の語: 結構、相当、どんどん、全然、すごく、めちゃくちゃ、バーッと

受けを残すのは、芯を言う所、体感、事実・因果・数字の確かさに掛かる所です。重なった受けを減らすときは、言い切りに変えるのではなく、2 つの受けを 1 つにまとめます。話者は、Claude が言い切りにした文を何度も「〜と感じています」に戻しています。口癖の程度の語は外します。ただし、話者は公開版にも 1 本に 0〜1 語を残しています (2026-11 時点で 55 本に 16 回)。話者が強めて言った所の 1 語だけは残してかまいません。2 語以上残っていたら外します。ただし、否定や比較の範囲を決めている程度の語 (「すごく〜したいわけではない」「全然違う」) は、外すと意味が変わるので、意味を保つ書き言葉に置き換えます (「そこまで〜したいわけではない」「まったく違う」)。

### 話し言葉を、中身で書き直す

素材の多くは、話者の音声入力です。話し言葉は 2 つに分けて扱います。曖昧な動作の言い方 (「足したり引いたりした」「いろいろいじった」) は、いつ・何を・どうしたかの事実に置き換えます (「何を話すかの取捨選択に時間をかけた」)。対象への評価・比喩・素の反応 (「マインクラフトでもここまでは掘らないだろう」「私は一体何を喋ったんだ」) は、話者の語のまま残します。推量や留保 (「〜と思う」「〜かもしれない」) の強さは保ちます。

## 表記

### ひらがなに開く

| 漢字 | ひらがな |
|---|---|
| 事 | こと |
| 時 | とき |
| 今 | いま |
| 出来る | できる |
| 更に | さらに |
| 是非 | ぜひ |

| 様々 | さまざま |

漢字が 7 字以上続いたら、開く場所を探します。

### そのほか

- 句読点は「、」「。」を使います
- 数字は半角にします (2022年、800人、3つ)
- 固有名詞はそのまま書きます (Slack、LINE、X、MOSH、note)
- 内部の言葉 (「群」「参照実装」「ネット」のような開発中の呼び名) は、一般の言葉に開きます

## 事実の扱い

- 数字は、素材や画像に写っている表記のまま書きます。単位の読み替えや換算をしません
- 件数は、元の判定まで確かめて数えます。ラベル (commit の feat など) をそのまま数えません
- 数字は、伝えたいことに効くものだけを出します。集計の数を出すなら、何を言うための数かを同じ文で示します
- 使って数日の機能は、評価を保留して紹介にとどめます (「1ヶ月使い倒してから判断します」)
- 一覧は、詳しい読者が違和感なく読める並びにします。日付のある出来事は時系列です

## 使わない言葉

lint が検出します。理由だけを書きます。

- ハイカロリーな修飾語 (圧倒的、革命的、究極、劇的、飛躍的、画期的など): 声を張ると、等身大の温度が消えます
- 最上級表現 (No.1、世界初、業界初、唯一): 客観的な根拠がない限り使いません
- 共感を求める表現 (〜ですよね？、皆さんも経験があると思いますが): 観客にマイクを向けません。自分が面白がって口に出す問いかけは使ってかまいません
- キザな言い回し (〜という確信に至った、言うまでもなく、ご存知のとおり)
- 型どおりの言い回し (本記事では〜ご紹介します、〜することが重要です、〜と言えるでしょう、いかがでしたでしょうか)

禁止語を避けても、AI っぽさは消えません。もっと効くのは、素材に無いことを書かない、型で畳まない、の 2 つです (`ai-tells.md`)。

## 炎上を避ける

本名と所属を公開しているので、個人 note でも MOSH のブランドに影響します。

- 人を動物・モノ・機械に例えません
- 特定の属性をステレオタイプ化しません
- 特定の個人・技術・思想を攻撃しません。「自分はこう思う」を崩しません
- SNS で一部を切り取られて拡散されても問題ないかを確認します

物や場所や歴史に向けた素の感想 (「マインクラフトでもここまでは掘らないだろう」) は、ここに当たりません。削ると、話者の声がいちばん出ている所が消えます。
