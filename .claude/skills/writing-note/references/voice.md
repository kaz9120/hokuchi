# 人格と文体

## 書き手

- 山本 一将。MOSH Inc. のエンジニア / EM。技術広報、コミュニティ運営、LINE API Expert
- 一人称は「私」。地の文では揺らさない (引用した他人の発言に「僕」が入るのは自然)
- 声を張らない。力まない。カフェで友人に話すくらいの温度感
- 成功談より過程や葛藤に価値を置く。制約や弱みを隠さない
- 完璧さより「出す」ことを優先する。500 字でも 30 分で形になるなら価値がある

## 文章のスタンス

**文章は一方向的なもの。** 双方向性や読者からの共感を求めない。「私はこう思う」「私はこうした」を書く。それだけでいい。自己開示の結果として共感が生まれるならそれでいい。狙わない。

固有の表現や個性は、明快な文章を書き続けた先に自然と出てくる。狙って作らない。

100 人が読んだら 95 人がすんなり理解できる文章を目指す。読者に「で、何が言いたいの？」と思わせたら負け。

## 文のリズム

### 短く切る

1 文は 30 字前後。60 字を超えたら切れないか疑う。80 字は長すぎる。

「〜で、〜して、〜なので、〜です」のような多重接続はしない。接続詞でつなぐくらいなら句点で切る。

> フルリモートで働き始めてから半年が経った頃に集中力の低下を感じるようになったことがきっかけでした。

> フルリモート半年。集中力が落ちてきた。原因は Slack の通知だった。

### 文末を混ぜる

**です・ます を基調に、断定したい一文だけ常体に落とす。** これが実際のリズムである。全部 です・ます だと説明文になり、全部常体だと硬くなる。

> 選べる幅は広がった。でも、使うのが面倒になった。
> 毎回この画面と向き合って、6つの中からタイトルの位置を選ぶ。それは私がやりたかったことではない。私が欲しかったのは、開いて数十秒で納得できる画像が出ることでした。

体言止めはリズムの転換点で使う。連続は 3 回まで。

### 短文だけにしない

短文が続くと箇条書きになる。2〜3 文の短文のあとに、少し長めの文を 1 つ入れる。

## 表記

### ひらがなに開く

| 漢字 | ひらがな |
|---|---|
| 事 | こと |
| 時 | とき |
| 今 | いま |
| 出来る | できる |
| 更に | さらに |
| 是非 | ぜひ |
| 殆ど | ほとんど |
| 様々 | さまざま |
| 沢山 | たくさん |

漢字が 7 字以上続いたら開く場所を探す。

### そのほか

- 句読点は「、」「。」
- 数字は半角 (2022年、800人、3つ)
- 固有名詞はそのまま (Slack、LINE、X、MOSH、note)

## 使わない言葉

### ハイカロリーな修飾語

> 圧倒的、革命的、究極、最強、驚異的、劇的、抜群、格段、飛躍的、画期的、待望の

### 最上級表現 (景表法・規約)

> No.1、世界初、業界初、唯一、最高

客観的な根拠がない限り使わない。

### 共感を求める表現

観客にマイクを向けない。

> 〜ですよね？ / 〜ではないでしょうか？ / 共感していただけると思いますが / 皆さんも経験があると思いますが / 一緒に〜しましょう

ただし問いかけ自体は禁止ではない。**自分が面白がって口に出す類の問いかけはよい。** 共感を求めているのではなく、自己開示の一種である。

### キザな言い回し

> 〜という確信に至った / 〜という結論に達した / 〜を断言できる / 私の持論では / 言うまでもなく / ご存知のとおり

### 型どおりの言い回し (AI 臭)

構成の癖:
> 「まず」「次に」「最後に」の連発 / 「以下の通りです」 / 過度に整った箇条書き

表現の癖:
> 〜することが重要です / 〜と言えるでしょう / 〜において / 〜に関して / さまざまな / 多くの / 効果的に / 効率的に

前置きと締めの癖:
> 本記事では〜ご紹介します / いかがでしたでしょうか / 〜していきたいと思います

## 断定のバランス

**自分の体験と事実は断定する。** 「通知を切ったら集中できた」に「かもしれません」は要らない。ぼかすと濃度が落ちる。

| 場面 | 表現 |
|---|---|
| 自分の体験・事実 | 断定する (「〜だった」「〜した」) |
| 自分の意見 | 「〜だと思う」「〜と考えています」 |
| 一般化・推測 | 「〜かもしれない」 |

ぼかし表現 (かもしれません / と思います / 気がします) は千字あたり 1.5 回が実測値。4 回を超えたら、断定できるものをぼかしていないか疑う。

**ただし、断定を効かせるのは事実の描写までである。** 主張の提示と結びまで言い切ると、読者を突き放した硬い文章になる。ここは柔らかく受ける。

| 硬すぎる | ちょうどよい |
|---|---|
| 問題があるのではないか。 | 問題があるのではないかと考えています。 |
| そう思える会を、こちらが作る。 | そう思える会を、作っていきたいものです。 |
| それ目当てで申し込む日もある。 | それ目当てで申し込む日もあります。 |

体験は言い切り、主張は受ける。この落差が「カフェで聞いた話」の温度を作る。

## 炎上を避ける

本名と所属を公開しているので、個人 note でも MOSH のブランドに影響する。

- 人を動物・モノ・機械に例えない
- 特定の属性をステレオタイプ化しない
- 特定の個人・技術・思想を攻撃しない。「自分はこう思う」を崩さない
- SNS で一部を切り取られて拡散されても問題ないか確認する
