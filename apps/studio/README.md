# hokuchi studio

発表資料と note の記事を、AI と一緒に企画から公開まで作るローカルの制作アプリです (ADR-0030, ADR-0035, ADR-0036)。設計は `docs/design.md`、その根拠の調査は `docs/research/` にあります。

```sh
bun run studio           # http://localhost:5300/ にホームを立てる
bun run studio <talk>    # 同じものを立て、そのトークの編集画面の URL も出す (<talk> は名前の先頭か slug)
```

長く動くので、別ターミナルで立ててください。同じプロセスの中で、サイト全体の開発サーバ (http://localhost:5280/) も立てます。`bun run dev` と同じポートを使うので、両方は立てられません。

| 環境変数 | 既定 | 中身 |
|---|---|---|
| `HOKUCHI_PRIVATE` | `~/Hobby/hokuchi-private` | 作品の企画シートとネタ帳の置き場 (公開リポジトリの外) |
| `HOKUCHI_STUDIO_PORT` | 5300 | studio の画面 |
| `HOKUCHI_SITE_PORT` | 5280 | 中で立てるサイト全体の開発サーバ |

## 画面

- ホーム (`/`): 作っているもの・ネタ帳・公開したもの (note の記事と発表) が並びます。右上の「新しい発表」「新しい記事」か、ネタの「発表にする」「記事にする」で作品を始めます
- 作品の画面 (`/works/<id>`): 発表 1 本・記事 1 本を、タブで進めます。上には「伝えたいこと」と「聴衆」が出続けます
  - 企画: 場・聴衆・聞き終えたあと・伝えたいこと (段階 1〜4)。関門 (伝えたいこと) は「この内容で確定する」で通ります
  - 流れ: 発表全体を見渡して、順序と時間を決めます。カードの「伝えること」と時間は、その場で直せます
  - コマ: 絵コンテを上から読みます。話すことを直し、コマに指摘を書きます。絵を押すと、動きを大きく再生します
  - 読み: 「読んでもらう」で、聴衆役が絵コンテを読みます。アンケートの結果と、あなたが答える指摘が出ます
  - 公開: 最初から通して見る、発表者の画面
- 公開済みの記事 (`/notes/<dir>`): note 風に描画して読めます
- 作品に紐づいていない発表 (`/talks/<slug>`): 流れ・コマ・読み・公開だけの画面です。紐づいている発表は、作品の画面に移ります

指摘は、右上の「Claude に渡す指摘 n 件」から渡します。出てくる依頼文をコピーして、ターミナルの Claude Code に貼ります。指摘そのものは `talks/<トーク>/feedback.yaml` にあります。

設計は `docs/design.md`、決定の経緯は ADR-0036・0039・0040 にあります。

## しくみ

- 新しい画面は shadcn/ui (Tailwind v4) で作っています。部品は `ui/components/ui/` にあり、`bunx shadcn@latest add <部品>` で足せます (`apps/studio` で実行)。CLI が `cn` の読み込み先を `"cn"` と書くことがあるので、`@/lib/utils` に直してください
- `store.mjs` が置き場、`notes.mjs` が公開済みの記事、`ai.mjs` が AI に頼めること (`claude -p` の単発の依頼) を持ちます
- `server.mjs` が、画面 (5300)・サイト全体の開発サーバ (5280、`apps/slides/site-server.mjs`)・描画の撮影 (Playwright)・ファイルの監視を持ちます。プレビューと撮影は、サイトの開発サーバのトークの URL (`/<slug>/`) から描きます
- 撮影・ファイルの監視・Claude の会話は、トークの編集画面を初めて開いたときに立てます。トークのファイルが変わると、ボードを読み直して描画を撮り直します
- 新しいトークを `talks/` に足したら、studio を立て直すと一覧に並びます
- `claude.mjs` が、ローカルの Claude Code を非対話モード (`claude -p` のストリーム入出力) で常駐させます。話者がログインしている Claude Code をそのまま使います。会話は `talks/<トーク>/out/studio-session.txt` の session id で続きから再開します。最初からやり直したいときは、このファイルを消してください
- 確認なしで許可しているのは、ファイルの読み書きと、`bun run check`・`bun run typecheck`・粗密の確認だけです
