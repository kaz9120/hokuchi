# hokuchi studio

絵コンテのボードを見ながら、Claude とチャットして発表資料を作るローカルの制作アプリです (ADR-0030)。

```sh
bun run studio <talk>    # <talk> は talks/ の中の名前の先頭 (例: 2026_09_29)。省略すると最新のトーク
```

長く動くので、別ターミナルで立ててください。http://localhost:5300 で開きます。

## 画面

- 左: 絵コンテのボード。シーンごとに、状態の縮小画像を横に並べた帯が出ます。文字はシーンの名前と、伝えることだけです。画面の説明は、縮小画像にカーソルを乗せると出ます。右上の点は、動きの役割が付いた状態です
- 右上: プレビュー。状態を選ぶと、その状態への遷移を再生します。← → キー (またはボタン) で、発表の順に状態を送れます
- 右中: 選んだ状態の詳細。画面の説明・動きの役割・話すことが出ます。話すことは、その場で直して欄の外をクリックすると絵コンテに保存されます
- 右下: Claude とのチャット。選んだ状態が文脈として付きます (入力欄の上のラベルをクリックすると、全体についての相談に切り替わります)。Enter で送信、Shift+Enter で改行です

上の帯には、絵コンテの規模・実装の進み具合・検査の結果が出ます。「検査する」で `bun run check` を回します。

## しくみ

- `server.mjs` が、トークの開発サーバ (5281)・画面 (5300)・描画の撮影 (Playwright)・ファイルの監視を持ちます。トークのファイルが変わると、ボードを読み直して描画を撮り直します
- `claude.mjs` が、ローカルの Claude Code を非対話モード (`claude -p` のストリーム入出力) で常駐させます。話者がログインしている Claude Code をそのまま使います。会話は `talks/<トーク>/out/studio-session.txt` の session id で続きから再開します。最初からやり直したいときは、このファイルを消してください
- 確認なしで許可しているのは、ファイルの読み書きと、`bun run check`・`bun run typecheck`・粗密の確認だけです
