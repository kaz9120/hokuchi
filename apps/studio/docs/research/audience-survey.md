# 聴衆役のアンケートの調査 (2026-10-13)

聴衆役 (AI が演じるペルソナ) に、読んだあとで答えてもらうアンケートの項目を決めるための調査です。決定は ADR-0039 にあります。

## 1. slide:ology にあるもの

本に、点数を付ける評価表はありません。材料になる記述は 4 つです。

- 聴衆を知る 7 つの問い (p.35)。どんな人か／なぜここにいるのか (何を得ようとしているか)／何に悩んでいるか／その問題をどう解決するか／何をしてほしいのか／どんな反発を受けるか／最適なアプローチは何か。前提は「聴衆は『あなた』を見にくるのではなく、『あなたがどんなメリットをもたらしてくれるのか』を確かめにくる」
- 制作プロセスの図にある「検証」の項目 (p.31)。メッセージの側は「聴衆を説得できているか／ギャップを特定する／現状を打破できているか」。ビジュアルの側は「反応が得られそうか／統一感あるビジュアルか／視線の動きは混乱しないか」。デリバリーの側は「リハーサルを繰り返す／自分の姿を録画してみる／フィードバックを求める」
- 同僚に見せる助言の工程 (p.54)。「スケッチがポイントを押さえたものかどうか、評価してもらう」。相手が戸惑ったら、不明な点を教えてもらう
- うまくいったかの見分け方 (p.269)。聴衆が「新たな見識を得た」「行動を起こそうという気になった」「自分の態度を改めようと思った」と感じていれば、うまくいっている。感動は「それまでの疑問が氷解し、全てが腑に落ちた瞬間」に来る (p.277)

7 つの問いは、聴衆を描くための欄です。裏返すと、聞き終えたあとの質問になります。「何を得ようとしているか」は「それは得られたか」に、「どんな反発を受けるか」は「その引っかかりは解けたか」になります。

## 2. 本の外にあるもの

- 口頭発表の評価表で、妥当性を確かめた研究があります。Van Ginkel ら (2017) は 11 の基準を、内容・構成・聴衆との相互作用・デリバリーの 4 つに分け、5 段階で採点します。高等教育の専門家 38 人で妥当性を確かめています。基準の一覧は有料の本文にあり、確認できていません
- これらは、評価者が話者を採点する表です。聴衆が自分の体験を答えるアンケートで、妥当性を確かめたものは、今回の調査では見つかりませんでした
- カンファレンスの運営の実務では、次のことが勧められています。項目を少なく保つ (長いと途中でやめる人が増える)。観点ごとに分けて採点し、どこが弱いかを見えるようにする。好きだったかではなく、何を持ち帰ったかを聞く。自由記述は 1 つに絞る

## 3. 自分たちの実績 (2026-10-12、KomeKaigi の絵コンテ)

4 人の聴衆役に 3 周読ませました。2・3 周目は「来た甲斐を 10 点満点で」とだけ聞いています。

- 点数は 6〜7 点から動かず、何が足りないのかは点数から読めませんでした。足りなかったのは言葉ではなく材料 (仕事の側の実例) で、これは自由記述から分かりました
- 4 人の指摘は 8 割がた重なりました。同じモデルが演じているためです。効いたのは人数より立場の違いで、ベテラン役だけが「かけた時間」を聞き、学生役だけが「価値とは何か」でつまずきました
- 場面を番号で答えてもらったので、シーン id への置き換えを手でしました

## 4. 項目の案

5 段階 (1 まったく当てはまらない 〜 5 とても当てはまる) で、項目ごとに理由を 1 行もらいます。発表では「聞く」、記事では「読む」と言い換えます。デリバリーの項目は、声を入れる段階まで置きません。

| 群 | 項目 | 元にしたもの |
|---|---|---|
| 届いたか | 1. 得に来たものを得られた | 7 つの問いの 2 |
| | 2. 自分の悩みに触れていた | 7 つの問いの 3 |
| | 3. 新しい見方を得た | p.269 |
| 分かったか | 4. 話の筋を最後まで追えた | p.31 の検証 (ギャップ)、評価表の「構成」 |
| | 5. 画面はひと目で分かった | p.160 の 3 秒、p.31 の検証 (視線) |
| 動くか | 6. 主張に納得した | 7 つの問いの 6、p.31 の検証 (説得) |
| | 7. 明日やってみようと思うことがある | 7 つの問いの 5、p.269 |
| 総合 | 8. 同じ立場の人に勧めたい | カンファレンスの実務 |

自由記述は 2 つです。「いちばん伝えたかったことは何だと思ったか (1 文)」は、中核メッセージと並べて、届いたかを確かめます。「ここがこうなっていたら、もっと良かった (1 つ)」は、いちばん効く直しを聞きます。

コマへの感想は、シーン id と状態の番号を付けて書いてもらいます。種類は 5 つです。分からない言葉／話が飛んだ／読み切れない／納得できない／良かった。

集計では、「直せば済むこと」と「話者の材料や判断が要ること」を分けて出します。
