LINE Messaging API の限定公開が2016年の4月ごろ、ということで10周年を記念したいつもよりちょっと規模の大きいMeetupを開催しました！

:::embed{service="external-article" url="https://weekly.ascii.jp/elem/000/001/147/1147459/"}
**LINE、Botアカウントを自由に開発できるトライアルアカウントを先着1万名無償提供 - 週刊アスキー**
LINEはAPI公開に先駆けて1万人限定でBot APIアカウントを無償提供した。
weekly.ascii.jp
:::
