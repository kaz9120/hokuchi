## 5/26 (火) LINE APIで試したんだけど、聞いてほしい Night LT #02

LINE Developer Community が定期的に開催しようとしている LT 会で、今回は司会を務めました。

最近は企業の技術広報が主催するイベントも公募の登壇枠がないことが多く、気軽に LT に挑戦できる場が減ってきていると感じています。

こういった場を作り続けるのはコミュニティの責務と信じ、今後も継続していけたらと考えています。

https://linedevelopercommunity.connpass.com/event/389723/

## 5/29 (金) LINEからAIエージェントを操る ─ LINE × Claude Code / OpenClaw

こちらは私が企画したイベントでした。

我々エンジニアから見ると LLM は普及しているかもしれませんが、世の中をみたらまだ全然使ったことがない人も多いと思います。そういった方でも使っているのは LINE で、なんとか LINE をインタフェースとした AI の話ができるといいなと思っていました。

オンライン・オフライン合わせて80名を超える申し込みをいただき、懇親会でもあまり見たことがない切り口で興味を持って参加したとの声を頂きました。

まだまだ出来そうな気がするので、AI がより身近になっていく世界を目指して、次の企画に繋げたいと思います。

https://linedevelopercommunity.connpass.com/event/392807/
