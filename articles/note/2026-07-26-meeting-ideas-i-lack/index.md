7月25日の大吉祥寺.pmで、wabiさんがこんな話をしていました。

> 「あなたがコミュニティに参加する理由はなんですか」

コミュニティでよくお会いする25人に、同じ質問を投げたそうです。  
私はその1人でした。回答は8つの理由に整理されて、私の答えは⑦「その場に居合わせないと、出会えないものがあるから」に入りました。

掲載されたのは私の想いの一部なので、この機会に残りを書いておきます。

:::embed{service="speakerdeck" url="https://speakerdeck.com/wabi_1318/aishi-dai-ni-nazeenziniahamadaji-marunoka"}
:::

## 覚えているのは技術のほうではありません

少し前の勉強会で、Geminiを使って手品を披露してくれた人がいました。  
タネはよくできていて、ChatGPTやClaudeでは同じ演出ができない理由まで説明してくれました。

でも覚えているのは、タネのほうではありません。  
その場にいた全員が同時に「えっ」と声を上げた瞬間です。

手品と技術を結びつける発想は、私からは出てきません。  
私が出かけるのはこういう考えに会うためです。

## 大雨の日に限って、足が向きます

電車が止まっているような日ほど、なぜか行きたくなります。

人数が少なくなること自体は気になりません。こんな日にわざわざ来る人を見てみたい、という好奇心が勝ちます。天邪鬼というわけではなく、私は基本的になんでも面白いと思ってしまうたちです。

## 半年前は相手のためだと書きました

1月にLINE API Platform Evangelistになったとき、こんなことを書きました。

> でも、そういう「小さくて尖った情熱」から生まれるアイデアは、私には絶対に思いつけないものばかりです。  
>   
> そして同時に、アイデアはあるのに実現する方法がわからなくて止まってしまう人も多いことを感じてきました。  
>   
> そんな方々に対して、私は何ができるだろうか。ずっと考えてきたテーマです。

あれは嘘ではありません。ただ、相手のためという側からしか書いていませんでした。裏返すと、自分のためでもあります。  
私が持っていないものを持っている人に会いに行きたい。

:::embed{service="note" url="https://note.com/kyamamoto9120/n/nfd82304e4849"}
**LINE API Platform Evangelistになりました**
:::

運営をしていていちばん嬉しいのも、初めて参加した人が「また来たい」と言う瞬間です。教えたわけではなく、その人の中にもともとあった一歩を見せてもらう。それだけのことなのに、何度経験しても飽きません。

## 欲はあるし、全部には行けません

私も人間なので欲はあります。この活動が生活を豊かにしてくれる糧になるなら嬉しい。ただ、その場に損得勘定は持ち込みません。何を返してもらえるかを考えずに渡した先で、いつか困っている自分を誰かが助けてくれる。それでいいと思っています。

面白そうな場は無限にあります。時間と体力は有限で、家庭の事情もあります。運営や登壇の立場なら必ず行きますが、選択の余地があれば休むこともあります。いつも天秤にかけています。

それに私は、情報収集に限ればそこそこ一人で完結できてしまうタイプです。娯楽も、妻と過ごす時間さえあれば十分だと思ってしまいます。

それでも、来週も勉強会の予定を入れています。  
私が持っていない何かを求めて。
