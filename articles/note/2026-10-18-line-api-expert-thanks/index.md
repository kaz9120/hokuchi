初代で、最後の LINE API Platform Evangelist になりました。

10月15日、日本の LINE API Expert 制度と LINE API Platform Evangelist（LAPE）制度の終了が発表されました。2026年末の任期満了で終わります。

https://developers.line.biz/ja/news/2026/10/15/line-api-expert-program-in-japan-will-be-discontinued/

## 運営を任せてもらえた1年でした

私は2024年に LINE API Expert に認定され、2026年1月に LAPE になりました。

1月の note には、「できた！」に変わる瞬間を一つでも多く見たいと書きました。正直、これはやりきれていません。  
春ごろから制度の行き先を考えることが増え、この半年は大変でした。

https://note.com/kyamamoto9120/n/nfd82304e4849

それでも、LAPE になってよかったと思っています。

LAE だった2年間、私がしていたのはイベントの企画でした。LAPE になってからは、コミュニティ全体を見るようになりました。いちばん嬉しかったのは、Discord で質問や相談が届くようになったことです。

1本ずつイベントを企画するのではなく、コミュニティを運営している。そう感じられたのは、この制度があったからです。

## ありがとうございました

LINEヤフーのみなさん、この制度を続けてくださって、ありがとうございました。一緒に走ってくれたしげるさん、スペシャルマンさん、前田さん。LAE のみなさん。本当にありがとうございました。

形は変わりますが、コミュニティは続けるつもりです。その話は、またあらためて。
