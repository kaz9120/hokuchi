最弱にしても、勝てませんでした。

小学5年生のとき、両親が仕事用に買ったパソコン（たしか NEC）に「AI将棋」というソフトが入っていました。それまで知っていたのはファミコンの森田将棋だけだったので、あまりの強さに驚きました。

将棋は父に教わりましたが、父は普段家にいなかったので指す相手がいませんでした。そのため勝てなくても強い人と将棋できるのが割に楽しくて、そのままハマりました。

世界コンピュータ将棋選手権を知ったのも、このソフトからです。AI将棋は、大会では「YSS」という名前で出ていました。

最近の note では、Claude Code でコンピュータ将棋を作り直している話を書いています。

https://note.com/kyamamoto9120/n/n8e50f15a69e0

今回はその根っこ、なぜコンピュータ将棋だったのかの話です。

## 将棋が好きで作りたかった

当時は RPGツクールも流行っていて、「作りたい」と思うハードル自体は低かったんです。「プログラミング」という言葉も聞いたことがありました。将棋が好きで、プログラミングもやってみたい。だから作りたい。それくらいの気持ちでした。

独学でプログラミングと機械学習を学び、大学を選ぶときに強化学習という分野を知りました。試行錯誤しながら自分で強くなっていく学習で、機械学習に詳しくなかった私には「The 人工知能」に見えたんです。これをやりたくて、芝浦工業大学に進みました。

## 大学3年で選手権に初めて出た

入学してすぐ、学科の友人たちとコンピュータ将棋を作り始めました。強くはなかったのですが、その話が強化学習を研究している五十嵐先生の耳に届き、学部2年から一緒に研究させてもらえることになります。

大学3年の5月、第20回世界コンピュータ将棋選手権に「芝浦将棋」のメンバーとして初参加し、7位入賞と新人賞をいただきました。

## 一から作ったのが「ひまわり」

芝浦将棋のテーマは、強化学習で将棋が強くなるかでした。土台はソースコードが公開されている Bonanza で、ルールや、指し手を読む「探索」の部分は Bonanza のままです。

私は全部を自分で書きたくて、大学卒業後は研究室を離れ、個人で「ひまわり」を一から開発しました。

名前に深い意味はありません。当時「sunfish」というソフトがいたので、fish を flower に変えて「sunflower」。さすがに紛らわしいので、日本語にしました。

後になって、棋士の窪田義行さんに「ひまわりは太陽を向いて咲くのが良いですね」と声をかけていただきました。それは良いと思い、以降は後付けでそれを由来として語ることもありました。

## 2015年、YSS に勝って9位

ひまわりの最高成績は、2015年の第25回大会の9位です。この年は探索も学習もがんばれていて、自信がありました。

選手権は3日制です。初日の一次予選、2日目の二次予選を経て、二次予選の上位8チームが最終日の決勝に進みます。

二次予選では YSS に勝ちました。小学生のころ、最弱にしても勝てなかった AI将棋です。満足感がありました。

ただ、決勝に残ったのは YSS のほうでした。ひまわりは勝ち数で並び、対戦相手の勝ち点の合計で比べるソルコフで 0.5 差の9位。あと一歩で決勝でした。悔しかったですね。

その差を生んだのは、Selene というソフトに負けた1局です。

玉が敵陣に入って条件を満たせば、宣言するだけで勝てる「入玉宣言法」というルールがあります。この対局は、選手権の歴史で初めて宣言による勝ちが出た将棋でした。負けた側が、ひまわりです。

松本博文さんの『棋士とAIはどう戦ってきたか』には、こう書かれています。

> ひまわり開発者の山本一将さんは、感動していました。確かに痛い１敗を喫したことには違いありません。しかしSeleneの見事な宣言勝ちについては、称える以外に他はありませんでした。
*https://note.com/mtmt81/n/nacf0b2b2ca28*

グッドルーザーとして描いてもらっていますが、引き分けなら決勝に残っていたかもしれないと思うと、普通に悔しいです。

https://note.com/mtmt81/n/nacf0b2b2ca28

## 9位でやり切って、7年止まった

その後もコロナ前の2019年まで選手権には出ていました。ただ、途中からはソフトを改善せず、前年と同じもので参加するだけです。

結婚して時間が取れなくなったのもありますが、何よりモチベーションが薄れていました。世界9位で、ちょっとやり切ってしまったのかもしれません。

翌年の大会がコロナで中止になり、そのまま7年。やりたい気持ちはずっとありましたが、勝つための実装にかける時間を考えると、面倒のほうが勝っていました。

それが今年、Claude Code を使っているうちに、これなら作れる気がしてきて、また一から開発を再開しています。
